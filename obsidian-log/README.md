# obsidian-log

The project's working log, kept as an Obsidian vault (open this folder in Obsidian; start at `00_INDEX.md`).

| Note | Contents |
|---|---|
| `SESSION_LOG/YYYY-MM-DD.md` | What was asked, built, found and fixed, in order |
| `Decisions.md` | Each decision and why |
| `Learnings.md` | Lessons for future work |
| `Open Questions.md` | Questions raised and how they were resolved |

Entries are written by a Claude Haiku agent from facts the main agent gives it, then reviewed and committed by the main agent.
