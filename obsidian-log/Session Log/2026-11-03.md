## Database Review (✓ Complete)
- **Choice:** PostgreSQL over SQLite/MySQL/MongoDB
- **Why:** UNIQUE(tableId, slotStart) constraint at DB level prevents double-booking; immutable audit-log trigger; transactions; free hosting (Neon/Supabase)
- **Schema fixes identified:**
  - Use `@db.Timestamptz` for all timestamps
  - Add short human reservation code (e.g., RSV-7K3Q9X)
  - Revoke UPDATE/DELETE grants on AuditLog table for immutability
  - Fixed slots → unique constraint is sufficient (flexible slots would need tstzrange exclusion constraint)
